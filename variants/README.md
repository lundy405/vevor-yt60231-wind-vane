# Earlier versions (superseded)

The main files in `../stl/` are **v5**: no ballast nuts, a solid printed barbed arrow, and a 3 mm shorter tail. The cap is the same as v4.

| Folder | What it was |
|---|---|
| `v1_big_arrow/` | First one-piece vane with a large arrow |
| `v2_flat_hub/` | Flat hub, still one piece |
| `v3_estimates/` | Two-part cap-and-blade, dimensions estimated from photos |
| `v3_final/` | v3 after caliper measurements; blade still used M6 nut ballast |
| `v4_teardrop/` | Teardrop ballast pod; cap and skirt match v5 |

Print the main v5 STLs unless you specifically want an older blade.
